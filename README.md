## About the Game

**Walk inside real device cloud data center 3D** is an atmospheric, perspective-shifting 3D simulation game built entirely using **WebGL and Three.js**. 

Inspired by real-world camera anomalies inside proprietary mobile cloud enterprise labs, this game shrinks the player down to navigate an endless corridor of physical server racks, cable arrays, and active hardware infrastructure slots. The entire simulation is framed within a custom virtual smartphone camera user interface, turning hardware constraints into immersive visual mechanics.

### 🚀 Key Features

* **Infinite Procedural Environment:** Explore a seemingly endless data center corridor that dynamically generates server racks, data arrays, and glowing status indicators as you walk.
* **Hardware-Accurate Camera Logic:** Experience realistic device-specific camera behaviors mapped directly from real hardware setups:
  * **iPhone 18 Aisle View:** Offers wide, open-angled clearance allowing the player to look out at the surrounding infrastructure grid and atmospheric overhead light reflections.
  * **Android Sled View:** Rotates into an enclosed, pitch-black state on both sides to perfectly simulate the tight spacing of universal device mounting sleds.
* **Dynamic Environment Compiling:** Click on any hardware listing from the menu panel (such as the *iPhone 18 Pro Max*, *Galaxy S26 Ultra*, or *Pixel 11 Pro*) to dynamically bundle and initialize 1 of 20 randomized server pipeline variations.
* **Integrated HUD Controls:** Fully detailed custom interface featuring real-time connection status logs, an interactive movement D-pad, directional flight toggles (**JUMP / FLY**), speed scale adjustments, and a responsive smartphone framing overlay.

### 🎮 Controls

* **Move Around:** Use the **W, A, S, D** or **Arrow Keys** (or click the on-screen D-pad)
* **Jump / Fly:** Tap **Spacebar** or click the **JUMP/FLY** interface buttons
* **Look Around:** Click and drag your mouse across the scene to change your angle of observation
* **Switch Environments:** Click different terminal list entries on the dashboard panel to clear the canvas and re-initialize the infrastructure loop

### 🛠️ Built With

* **Three.js** (3D WebGL Library)
* **HTML5 Canvas & JavaScript** (Dynamic procedural architecture & input routing)
* **CSS3 Custom Variables** (Responsive laboratory control framework)
